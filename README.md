# Jogo

Jogo 3D no navegador com os personagens das histórias (O Menino que Ninguém Quis Ajudar).

**Teste 1:** o bonequinho (Rafael) andando, correndo e pulando numa terra plana.

- Celular: arraste do lado esquerdo pra andar, do lado direito pra girar a câmera, botões PULAR e CORRER.
- Computador: WASD ou setas, Shift corre, Espaço pula.

Pra montar o `index.html` depois de mexer em `src/`: `python3 build.py`.
